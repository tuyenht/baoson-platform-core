# i18n chuẩn hoá (Control Plane)

Mục tiêu: **1 nguồn duy nhất**, **tốc độ tối đa**, **tránh trùng lặp**.

## Quy ước
- **Nguồn canonical**: `apps/control-plane/lang/{locale}/ui.php`
- **Frontend dùng file generated**: `apps/control-plane/resources/js/locales/translations.json`
- **Không dùng** `apps/control-plane/resources/lang/*` (tránh 2 nguồn dữ liệu).

## Vì sao cách này “tốt nhất” cho dự án này?
- **Backend** (Laravel) dùng `lang/*` (PHP) → ổn định, cache/OPcache tốt, chuẩn Laravel cho validation/auth.
- **Frontend** (React) vẫn đổi ngôn ngữ **instant**, không mất state (không reload), vì đọc JSON đã bundling sẵn.
- Chỉ có **một nơi chỉnh bản dịch** (ui.php) → không lệch, không trùng.

## Cách cập nhật bản dịch UI
1) Sửa file: `apps/control-plane/lang/{locale}/ui.php`
2) Chạy export:
   - `php artisan i18n:export`

## Build
`pnpm run build` đã tự gọi `php artisan i18n:export` trước khi build Vite.

## Lưu ý
- Các message auth/validation/flash nên ở `lang/{locale}/*.php` theo chuẩn Laravel.
- Nếu cần thêm namespace UI khác ngoài `auth`, mở rộng export trong `App\Console\Commands\I18nExport`.
